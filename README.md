This website reflects the aesthetic caliber of an international digital design studio, engineered with strict color hierarchy and spatial depth:
- **Midnight Background**: `#080B10`
- **Deep Slate Surfaces**: `#101820`
- **Elevated Interactive Surfaces**: `#16242B`
- **Accents**: Emerald (`#35E6B0`), Cyan (`#36D9F5`), Electric Lime (`#D8FF58`), and Soft Violet (`#A78BFA`)
- **Primary & Secondary Typography**: `#F4F7F8` on `#8A99A6` for WCAG AAA contrast
- **Interactive Physics & Engineering Depth**:
  - 3D Interactive Creator Showcase with dynamic specular glare and floating telemetry badges
  - Interactive **Architecture Pipeline Diagram** with sequential stage inspection
  - Deep-dive **Engineering Case Studies (Sections A through M)** with hash-based deep linking
  - **Command Palette** (`Cmd+K` / `Ctrl+K`) for lightning-fast search & section jumping
  - Interactive **Skill Ecosystem Explorer** with live search and category filtering

  - Verified **Achievements & Timeline** without inflated claims or fabricated metrics

## ⚙️ Quick Start

### 1. Installation
```bash
npm install
```

### 2. Local Development Server
```bash
npm run dev
```
Open [http://127.0.0.1:5173/](http://127.0.0.1:5173/) in your browser.

### 3. Production Build
```bash
npm run build
```
Creates an optimized, tree-shaken static bundle in the `/dist` directory.

### 4. Production Preview
```bash
npm run preview
```

## ✏️ How to Customize Your Content (Single Source of Truth)

All portfolio data—including personal information, social links, resume content, project architectures, skills, timeline milestones, and research focus areas—is centralized in:
